# منصة Researcher / Mostafa Ibrahim التعليمية

منصة تعليمية كاملة بالهوية الذهبية/الكحلي من الصورة المرفقة، بالعربية والإنجليزية مع الوضع الليلي والنهاري.

## الصفحة الرئيسية
- هيدر بالشعار الذهبي (النسر) والاسم والتخصص، وأزرار: اللغة، الوضع الليلي/النهاري، الإشعارات، تسجيل الدخول/إنشاء حساب.
- واجهة متحركة بخلفية أثرية وفقاعات/جزيئات تاريخية متحركة، عنوان رئيسي، بطاقات مميزات (متابعة التقدم، امتحانات تفاعلية، مدرس متاح دائماً، إنجازات وشهادات)، وأرقام إحصائية.

## الحسابات
- التسجيل: الاسم الثلاثي، رقم واتساب، رقم ولي الأمر، العنوان، المرحلة (1 ثانوي، 2 ثانوي، 3 ثانوي، 3 إعدادي)، كلمة المرور.
- الحساب يبقى «قيد الانتظار» ولا يستطيع الدخول حتى يوافق الأدمن.
- حساب الأدمن admin@info.com يدخل من نفس صفحة الدخول ويصل للوحة التحكم الكاملة.

## لوحة تحكم الأدمن
- الطلاب: تبويب لكل مرحلة + تبويب «الكل» + تبويب «قيد الانتظار»؛ قبول/رفض، تفعيل/إيقاف، إعادة تعيين كلمة المرور، عرض كل البيانات، طرد الطالب.
- حسابي: تعديل البيانات وكلمة المرور والصورة الشخصية.
- الفولدرات: إنشاء وحدات لكل مرحلة تضم الفيديوهات والامتحانات.
- الفيديوهات: رفع مباشر أو يوتيوب أو رابط خارجي؛ مجاني أو مقفول بكود مع عرض سعر الحصة، وفتحه بالكود يبقى دائماً.
- الأكواد: إصدار أكواد لكل فيديو بسعر محدد ومتابعة المستخدم منها.
- الامتحانات: أسئلة نص أو صورة باختيارات متعددة، تصحيح فوري وإظهار الدرجة فقط، وإظهار الإجابات الصحيحة للطلاب بعد «غلق الامتحان».
- التقارير: أداء كل طالب، وترتيب الأوائل وأول 3 في كل مرحلة على الصفحة الرئيسية للوحة.

## حساب الطالب
- تعديل بياناته وصورته، مشاهدة فيديوهات مرحلته، فتح المقفول بالكود، أداء الامتحانات ورؤية درجته، ومراجعة أخطائه بعد غلق الامتحان، تقرير مستواه، وترتيب أوائل مرحلته فقط.
- إشعارات عند نزول امتحان أو فيديو أو تغيّر ترتيبه.

## التفاصيل التقنية
- Lovable Cloud للحسابات وقاعدة البيانات والتخزين (صور شخصية، صور الأسئلة، الفيديوهات المرفوعة).
- جداول: profiles، user_roles، stages، folders، videos، access_codes، code_redemptions، exams، questions، options، attempts، answers، notifications.
- سياسات صلاحيات صارمة: الطالب يرى بيانات مرحلته فقط ولا يرى الإجابات الصحيحة قبل غلق الامتحان؛ الأدمن يتحكم في كل شيء.
- تصميم موحّد بنظام ألوان (ذهبي/كحلي) وخطوط عربية وإنجليزية، ودعم RTL/LTR.

## خطوات التنفيذ
1. تفعيل Lovable Cloud وإنشاء قاعدة البيانات والصلاحيات وحساب الأدمن.
2. نظام التصميم + الترجمة + الوضع الليلي + الصفحة الرئيسية المتحركة.
3. تسجيل الدخول/إنشاء الحساب مع نظام الموافقة.
4. لوحة تحكم الأدمن بكل تبويباتها.
5. لوحة الطالب: الفيديوهات، الأكواد، الامتحانات، التقارير، الترتيب.
6. الإشعارات ثم مراجعة نهائية للأمان والتجربة.
